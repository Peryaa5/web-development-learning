# Cyber Security Game

Небольшая браузерная игра в стиле pixel art на тему кибербезопасности.

Игрок управляет персонажем, который должен добраться до защищённой зоны и не попасть на заражённые участки сети. В игре есть главное меню, счётчик побед и поражений, случайная генерация препятствий и управление персонажем.

## Описание игры

Главная героиня находится в цифровом городе. Её задача — пройти через опасный участок сети, перепрыгнуть заражённые зоны и добраться до защищённого портала.
Игра выполнена в киберпанк-стиле с неоновым интерфейсом, пиксельной графикой и тематикой информационной безопасности.

## Возможности

- главное меню игры;
- кнопка запуска игры;
- счётчик удачных и неудачных попыток;
- управление персонажем;
- прыжок через препятствия;
- случайное расположение опасных зон;
- экран победы и поражения;
- оформление в стиле cyber security / pixel art.

## Управление

| Кнопка | Действие |
|-------|----------|
| ← | Движение влево |
| → | Движение вправо |
| JUMP | Прыжок |
